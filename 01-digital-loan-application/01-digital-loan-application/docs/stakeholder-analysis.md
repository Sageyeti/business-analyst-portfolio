# Stakeholder Analysis

| Stakeholder | Role | Needs / Expectations | Potential Concerns |
|---|---|---|---|
| Customer | Applies for a loan | Easy application and status updates | Worried about sharing personal information online |
| Loan Officer | Reviews applications | Complete information and documents | Incomplete customer applications |
| Branch Manager | Oversees approvals | Application tracking and reports | Difficulty monitoring pending applications |
| IT Team | Develops the system | Clear system requirements | Unclear or changing requirements |
| Compliance Team | Checks regulatory requirements | Proper documentation and controls | Missing or incorrect documents |
