# AS-IS Process Analysis

## Current Loan Application Process

The fictional financial institution currently uses a manual, paper-based loan application process.

### Process Steps

1. Customer visits the branch.
2. Customer fills out a paper loan application.
3. Loan Officer checks the application and supporting documents.
4. Loan Officer manually enters application details.
5. Branch Manager reviews the application.
6. Customer is informed of the loan decision.

## Problems Identified

1. Paperwork may be lost or damaged.
2. Manual data entry can cause errors.
3. Customers may not know their application status.
4. Processing may take longer due to manual reviews.
5. Managers may find it difficult to track pending applications.

## Business Impact

These problems may lead to delays, additional administrative work, and a poor customer experience.

*Note: This is a fictional case study created for portfolio practice.*
