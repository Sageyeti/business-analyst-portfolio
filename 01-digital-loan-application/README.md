# Project 01: Digital Loan Application & Approval System

## 1. Project Overview

This is a self-directed business analysis project focused on improving the loan application and approval process for a fictional financial institution.

The proposed solution is a digital system that allows customers to submit loan applications online and enables employees to review, track, and manage applications.

## 2. Business Problem

The current loan application process is manual and paper-based.

Potential problems include:
- Customers need to visit the branch to submit applications.
- Employees manually enter customer information.
- Application processing may take longer than necessary.
- Customers have limited visibility into application status.
- Managers may find it difficult to monitor pending applications.

## 3. Project Objectives

- Simplify the loan application process.
- Reduce repetitive manual data entry.
- Improve application tracking.
- Make the review process more organized.
- Provide customers with application status updates.

## 4. Project Scope

### In Scope
- Online loan application submission.
- Customer information collection.
- Document upload.
- Application status tracking.
- Employee application review.
- Loan approval or rejection recording.

### Out of Scope
- Actual loan disbursement.
- Credit bureau integration.
- Automated credit scoring.
- Real banking system integration.

## 5. Stakeholders

- Customers
- Loan Officers
- Branch Managers
- IT Development Team
- Compliance Team

## 6. Project Deliverables

- Stakeholder analysis
- AS-IS process analysis
- TO-BE process design
- Business requirements
- Functional requirements
- User stories
- Acceptance criteria
- UAT test cases

## 7. Project Disclaimer

This is a fictional portfolio case study created for learning and demonstration purposes. It does not represent work completed for an actual financial institution.
